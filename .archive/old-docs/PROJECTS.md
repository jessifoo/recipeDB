# 🎯 Example Projects You Can Build

This template works for **any type of application**. Here are examples:

---

## 📝 Recipe Database (Your Original Idea!)

```bash
./create-project.sh recipe-db
cd ../recipe-db
```

**What to add:**
- Recipe model (ingredients, steps, images)
- Ingredient tracking
- Meal planning
- Shopping lists
- User collections
- Recipe sharing

**Generators will create:**
- `packages/domain/recipe/` - Recipe business logic
- `packages/api/routers/recipe.router.ts` - tRPC endpoints
- `apps/web/src/app/recipes/` - UI components
