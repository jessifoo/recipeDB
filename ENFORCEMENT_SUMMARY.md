## 🎯 What's Enforced (Cannot Be Bypassed)

### 1. **ONE Package.json Only**

```
✅ /workspace/package.json          ← ONLY package.json
❌ /workspace/packages/*/package.json   ← BLOCKED by validator
```

**Enforced by:**
- Validator #0: `no-package-json-validator.js` (runs FIRST)
- Scans for any package.json in packages/
- Blocks commit if found

**Why:** AI cannot add dependencies to bypass central control.

---

### 2. **Blocked Import Paths**

```typescript
// ❌ AI tries this:
import { PrismaClient } from '@prisma/client';
// Result: TypeScript error - module not found

// ❌ AI tries this:
import winston from 'winston';
// Result: TypeScript error - module not found

// ✅ AI must use this:
import { db } from '@app/database';
import { logger } from '@app/logger';
// Result: Works!
```

**Enforced by:**
- `tsconfig.base.json` paths point blocked imports to non-existent paths
- TypeScript won't compile
- Can't even save file

---

### 3. **Branded Types (Type-Level Safety)**

```typescript
// ❌ AI tries this:
function getUser(id: string) { ... }
getUser('123');  // Type error

// ❌ AI tries this:
function save(data: unknown) { ... }
save(rawInput);  // Type error

// ✅ AI must use this:
import { UserId, Validated } from '@app/types';

function getUser(id: UserId) { ... }
getUser(UserId('123'));  // Works!

function save(data: Validated<T>) { ... }
save(validate(schema, rawInput));  // Works!
```

**Enforced by:**
- TypeScript type system
- Compile-time errors
- Impossible to bypass

---

### 4. **File Markers (Generator Enforcement)**

```typescript
/**
 * @generated by @app/generators:module
 * @generatedAt 2024-01-15T10:00:00Z
 */

export const __metadata = {
  [Symbol.for('@app/generated')]: true,
  generator: '@app/generators:module',
  generatedAt: '2024-01-15T10:00:00Z',
  version: '1.0.0',
};
```

**Enforced by:**
- Validator #1: Rejects files without marker
- All new TypeScript files must have this
- Forces generator usage

---

### 5. **No Duplicates**

**Enforced by:**
- Validator #2: AST analysis
- Finds duplicate exports (functions, classes, constants)
- Blocks commit if duplicates found

**Example:**
```
❌ DUPLICATE EXPORTS DETECTED

  function "createUser":
    - packages/domain/user/src/user.service.ts
    - packages/domain/admin/src/admin.service.ts
    
Remove duplicates or use existing implementation.
```

### 6. **Package Lockdown**

**Banned packages:**
- winston, pino, bunyan (use @app/logger)
- axios, got (use tRPC)
- typeorm, sequelize (use @app/database)
- yup, joi (use @app/validation)
- mobx, recoil (use Redux Toolkit)
- eslint, prettier (use Biome)

**Enforced by:**
- Validator #3: Checks package.json changes
- Blocks banned packages
- Warns on unapproved packages

### 7. **Directory Structure**

```
✅ packages/domain/*/src/*.service.ts    (allowed)
❌ packages/domain/*/src/*.component.tsx  (blocked)
```

**Enforced by:**

- Prevents mixing concerns
